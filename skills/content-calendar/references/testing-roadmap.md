## Test 1 — Carousel vs. video, same topic (added 2026-09-09, target: week of next Monday)

**Origin:** Graeham, 2026-09-09, right after `quick-carousel-engine` was
built: "make a note for this for next week individual one time post videos,
carousels even testing some carousels as videos and vice versa and seeing
which ones do better."

**What to run:** Pick 1-2 topics from that week's calendar. For each one,
produce BOTH:
- A one-time video post (Reel/Short, via the normal `content-creation-engine`
  pipeline), AND
- A quick carousel covering the same core message (via `quick-carousel-engine`)

Post both, same week, same topic, so the comparison is apples-to-apples
(not a video from a different topic vs. a carousel from a different topic).
Do this in both directions across the test — at least one topic that starts
as a video-first idea, redone as a carousel, and at least one that starts as
a carousel-first idea (e.g. a Category 1 trend/stat topic), redone as a
video — so the test isn't biased toward whichever format the topic was
originally suited to.

**What to measure:** pull both posts into the next weekly `content-calendar`
performance review (Windsor Instagram data, already automatic) and compare
reach, engagement rate, saves, and shares for the video vs. the carousel on
the same topic. Note it in that week's Analytics tab under a "Format Test"
callout, not just the normal Content Type Performance Matrix.

**Decision this feeds:** whether certain topic *types* (trend/stat data vs.
narrative/story topics) systematically favor one format over the other —
if so, that becomes a standing rule for which format a topic gets assigned
by default, instead of defaulting everything heavy to video.

**Status:** not yet run. Update this section with the actual topics picked
and the result once the test week happens.
